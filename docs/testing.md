# Testing

```bash
npm test             # unit, property, conformance and content tests (Vitest)
npm run build && npm run test:e2e   # Playwright journeys, accessibility, mobile (against the production build)
npm run check        # typecheck + lint + unit tests
npm run bench:trace  # trace reconstruction experiment (not a test; prints measurements)
```

Python 3 must be on `PATH` for the Python implementation tests; without it those tests are skipped and reported as skipped.

## Evidence the tests can fail

Mutation checks performed while building the suite (2026-10-19/20), each reverted afterwards:

| Injected bug                                                  | Caught by                                                                  |
| ------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Bubble sort skips swaps at index 2                            | 21 conformance cases (oracle)                                              |
| BFS adds 1 to one node's distance                             | 21 conformance cases (oracle)                                              |
| Quicksort leaves the pivot mark behind after moving the pivot | mark-semantics property, minimal counterexample `[0,0,1,1]`                |
| KMP falls back to 0 instead of `lps[j−1]`                     | 1 conformance case; then the KMP property, counterexample `["bbba","bba"]` |
| Kahn's algorithm skips one in-degree decrement                | 8 conformance cases (oracle)                                               |

Real defects found by the suite rather than injected: a stale pivot mark in quicksort, KMP's comparison count exceeding the bound stated in its lesson, a contradictory practice question, a dangling “related” link, and two accessibility violations (unfocusable scroll region, empty ARIA list).

## What tests do not prove

- Passing the conformance and property suites is **empirical evidence**, not a proof of correctness. Correctness arguments are in each lesson's Mathematics level.
- Automated accessibility checks cover a subset of WCAG; screen-reader walkthroughs have not been done yet.
- Lesson prose is not verified by tests (only its maths syntax, code and numbers).
- E2E runs in Chromium only; Firefox and WebKit are untested.
