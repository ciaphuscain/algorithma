# Security model and threat register

Scope: the current release (static lessons, in-browser execution of reviewed algorithms, Studio trace import, local progress, and a browser code sandbox that default builds ship switched off). Threats for features that do not exist yet are listed so they are designed in, not bolted on.

## Trust boundaries today

| Data                                  | Trust                            | Handling                                                                                                                                                                                                                                                         |
| ------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Algorithm modules, lesson content     | Trusted (code-reviewed, in repo) | Rendered as React elements; TeX through KaTeX with `trust: false`                                                                                                                                                                                                |
| Visualizer inputs typed by the user   | Untrusted                        | Parsed by `InputSpec.parse` only: strict grammar, size and range limits, errors listed back to the user                                                                                                                                                          |
| Imported trace JSON (Studio)          | Untrusted                        | `validateTrace`: schema, unknown-field rejection, resource limits, full semantic replay before rendering; rendered as text/SVG attributes, never HTML                                                                                                            |
| localStorage progress                 | Untrusted (user-controlled)      | Parsed defensively; shape-checked; failure falls back to empty progress                                                                                                                                                                                          |
| JavaScript typed into the code runner | Hostile                          | Runs only in the visitor's browser, in an opaque-origin `allow-scripts` iframe whose CSP forbids network and eval, inside a Worker with time and output limits; messages back are validated; off by default ([ADR-0007](decisions/0007-browser-code-sandbox.md)) |

## Threat register

| Threat                                                            | Surface                          | Impact                                                            | Mitigation                                                                                                                                                                                                                                                    | Residual risk                                                                                                                                                                                           | Test                                                                            |
| ----------------------------------------------------------------- | -------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **Untrusted code execution**                                      | Code tab runner (off by default) | Origin compromise, data theft, network abuse, resource exhaustion | Never on the server. ## Security headers

Set in `next.config.ts`: `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY`, `Permissions-Policy` denying camera, microphone and geolocation, and in production a Content-Security-Policy without nonces ([ADR-0006](decisions/0006-content-security-policy.md)). Rendering failures are contained by error boundaries around each structure panel and the visualizer.
